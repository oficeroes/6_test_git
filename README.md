# Python 学习与六级备考练习

本仓库收录 Python 编程练习和学习实验，不是一个有统一入口的应用程序。文件涉及基础语法、NumPy、Matplotlib、Tkinter、SQLite 与文件读写。

## 内容索引

| 文件 | 内容 |
| --- | --- |
| `class_test_6.py`、`sm_1.py` 等 | Python 语法练习 |
| `study_numpy.py`、`Study_NumPy_2.py` | NumPy 练习 |
| `study_matplotlib.py`、`study_matpoltlib.py` | Matplotlib 练习 |
| `study_tkinter.py`、`TkinterAndSQLTest.py` | Tkinter 界面练习 |
| `sqlite3_study.py`、`study_sql_*.py`、`testtt.py` | SQLite 练习 |
| `study_with_open.py`、`score.txt` | 文件读写练习 |

仓库还包含练习所用的 `.db` 数据库和 `.idea/` 编辑器项目文件。各脚本应按需单独查看；部分数据库练习会写入同目录数据库，运行前应先备份数据。本仓库没有统一依赖清单或自动化测试记录。
